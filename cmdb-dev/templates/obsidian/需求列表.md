# 需求列表

> [!warning] 只读视图
> 数据来自 `plan/01_Requirements/` 与 `plan/02_Bugs/`，由 ZCode 从 GitHub/Git 自动同步。

## 全部工单

```dataview
TABLE WITHOUT ID
  file.link AS "工单",
  title AS "标题",
  status AS "状态",
  github_issue AS "Issue",
  github_pr AS "PR",
  risk_level AS "风险",
  updated AS "更新"
FROM "plan/01_Requirements" OR "plan/02_Bugs"
SORT status ASC, updated DESC
```
