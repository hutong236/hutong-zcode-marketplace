# CMDB 研发首页

> [!success] 主入口
> # [[00_Dashboard/研发控制台|打开研发控制台]]
>
> 日常只需要查看这一页。工单与状态由 ZCode 从 Git/GitHub 自动同步维护，本目录只读。

## 快捷入口

- [[00_Dashboard/研发控制台|▤ 研发控制台]] — 待审批 / 进行中 / Blocked / Open Bugs / 最近完成
- [[00_Dashboard/研发看板|▦ 研发看板]] — 按状态分列的看板视图
- [[00_Dashboard/需求列表|☰ 需求列表]] — 全量工单清单

## 目录说明

| 目录 | 用途 |
| --- | --- |
| `00_Dashboard/` | 纯查询视图页，不含事实数据，由 ZCode 自动维护 |
| `01_Requirements/` | 需求工单，一文件一需求（`REQ-<Issue号>.md`） |
| `02_Bugs/` | Bug 工单（`BUG-<Issue号>.md`） |

> [!warning] 只读投影
> 事实优先级：GitHub 实际状态 > Git 状态 > 本地 Markdown > AI 推断。请勿手工修改本目录下的状态。

> [!note] 首次使用
> 视图页依赖 Dataview 插件，请在 Obsidian「设置 → 第三方插件」中启用 Dataview。
