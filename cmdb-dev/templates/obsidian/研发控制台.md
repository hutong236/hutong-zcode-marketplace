## Waiting Approval
```dataview
TABLE WITHOUT ID
  file.link AS "工单",
  github_issue AS "Issue",
  risk_level AS "Risk",
  next_action AS "Next"
FROM "plan/01_Requirements" OR "plan/02_Bugs"
WHERE status = "waiting_approval"
```

## Active
```dataview
TABLE WITHOUT ID
  file.link AS "工单",
  status AS "Status",
  github_issue AS "Issue",
  github_pr AS "PR",
  branch AS "Branch",
  agent_owner AS "Agent",
  next_action AS "Next"
FROM "plan/01_Requirements" OR "plan/02_Bugs"
WHERE status != "waiting_approval" AND status != "done" AND status != "blocked"
```

## Blocked
```dataview
TABLE WITHOUT ID
  file.link AS "工单",
  github_issue AS "Issue",
  github_pr AS "PR",
  block_reason AS "Reason",
  next_action AS "Next"
FROM "plan/01_Requirements" OR "plan/02_Bugs"
WHERE status = "blocked"
```

## Open Bugs
```dataview
TABLE WITHOUT ID
  file.link AS "Bug",
  github_issue AS "Issue",
  risk_level AS "Risk",
  agent_owner AS "Agent",
  next_action AS "Next"
FROM "plan/02_Bugs"
WHERE status != "done"
```

## Done
```dataview
TABLE WITHOUT ID
  file.link AS "工单",
  github_issue AS "Issue",
  github_pr AS "PR",
  image AS "Image",
  image_digest AS "Digest"
FROM "plan/01_Requirements" OR "plan/02_Bugs"
WHERE status = "done"
SORT file.mtime DESC
LIMIT 20
```
