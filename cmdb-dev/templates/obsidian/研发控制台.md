# CMDB 研发控制台
> 本页只读。状态由 ZCode 从 Git/GitHub 自动同步。

## Waiting Approval
```dataview
TABLE github_issue AS "Issue", risk_level AS "Risk", next_action AS "Next"
FROM "plan/01_Requirements"
WHERE status = "waiting_approval"
```

## Active
```dataview
TABLE status AS "Status", github_issue AS "Issue", github_pr AS "PR", branch AS "Branch", agent_owner AS "Agent", next_action AS "Next"
FROM "plan/01_Requirements"
WHERE status != "waiting_approval" AND status != "done" AND status != "blocked"
```

## Blocked
```dataview
TABLE github_issue AS "Issue", github_pr AS "PR", block_reason AS "Reason", next_action AS "Next"
FROM "plan/01_Requirements"
WHERE status = "blocked"
```

## Done
```dataview
TABLE github_issue AS "Issue", github_pr AS "PR", image AS "Image", image_digest AS "Digest"
FROM "plan/01_Requirements"
WHERE status = "done"
SORT file.mtime DESC
LIMIT 20
```
