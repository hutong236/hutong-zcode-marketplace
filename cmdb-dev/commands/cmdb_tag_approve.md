The user explicitly confirms Gate C for $ARGUMENTS. Call `cmdb_status` with GitHub refresh; require waiting_tag_confirm and merged SHA. For tag delivery call `cmdb_transition(approve_tag, actor=human:<identity>, patch.image_tag=<confirmed strict SemVer>)`; for skip call approve_skip. Skip is valid only under persisted delivery policy; call `cmdb_authorize(issue-close)`, close the exact Issue once, then record issue_closed. Tag path requires collision and default-branch ancestry checks. Call `cmdb_authorize(git-tag)` for one annotated-tag command naming both the confirmed tag and exact merged SHA, then a fresh `cmdb_authorize(git-push)` to push only that tag. Run protected commands with the Bash tool cwd set directly to the managed repository; do not use `cd` or `git -C`. Dispatch Build Checker; independently collect Actions artifact, Release metadata, GHCR digest, SBOM and provenance. Pass the two metadata objects and registry evidence to `cmdb_verify_delivery`; only that tool may record image_verified. Then authorize/close the exact Issue once and record issue_closed. Any build/evidence failure records block and leaves the Issue open. Never batch protected actions or invoke the legacy state CLI.
